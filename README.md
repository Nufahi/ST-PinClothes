# PinClothes для SillyTavern

Пункт **«Pinterest»** в волшебной палочке: открыть Pinterest, прикрепить картинку и получить короткое описание одежды через отдельный профиль подключения. Интерфейс рассчитан на телефон: полноэкранное окно, вкладки «Образ» / «Результат» и закреплённая снизу кнопка действия.

## Установка

В SillyTavern открой **Расширения → Установить расширение** и вставь ссылку:

```text
https://github.com/Nufahi/ST-PinClothes
```

### Ручная установка

Скопируй папку `ST-PinClothes` в каталог расширений своей установки:

```text
SillyTavern/public/scripts/extensions/third-party/ST-PinClothes/
    manifest.json
    index.js
    api.js
    style.css
    pinterest.svg
```

Перезагрузи страницу SillyTavern и открой **Pinterest** в волшебной палочке.

Чтобы открывать расширение прямо из сендбара, нажми кнопку настроек в самом окне Pinterest и включи **«Иконка в строке ввода»**. Перед меню ввода появится SVG-иконка Pinterest в цвете темы. Переключатель сохраняется; повторное выключение убирает иконку.

Логотип: [Pinterest из Simple Icons](https://simpleicons.org/?q=pinterest), CC0; SVG поставляется вместе с расширением.

Нужна версия SillyTavern, предоставляющая `SillyTavern.getContext().ConnectionManagerRequestService`, и включённый встроенный **Connection Manager**. Если список профилей пуст, включи его и создай профиль **Chat Completion**. Выбранная модель и провайдер должны поддерживать изображения; тип профиля сам по себе этого не гарантирует.

## Как пользоваться

1. Открой волшебную палочку → **Pinterest** или нажми его иконку в строке ввода.
2. Во вкладке **Образ** нажми стрелку рядом с поиском, чтобы открыть Pinterest. Можно заранее вписать поисковую фразу.
3. Скачай изображение с Pinterest обычным способом, вернись в Таверну и нажми **Добавить фото**. Нажатие на превью позволяет заменить фото. Также доступны перетаскивание и вставка изображения из буфера обмена внутри окна расширения.
4. Выбери сохранённый **профиль подключения** с vision-моделью. Профили перечитываются при открытии окна или кнопкой «Обновить профили».
5. При необходимости раскрой **Добавить пожелание**, введи комментарий и нажми **Описать одежду**.
6. Откроется вкладка **Результат**. Скопируй текст или нажми **Вставить в сообщение**: описание добавится в конец текущего черновика без автоматической отправки. Результат можно исправить вручную.

Пример результата:

```text
clothes: brown leopard-print halter top (ruched, tie-neck, backless), baggy low-rise light-wash denim jeans
```

### Правила описания

Системный промпт требует короткую английскую строку `clothes: ...`: цвет, принт, тип одежды, крой и заметные детали. Без выдуманных подробностей, внешности человека и фона.

По умолчанию исключены обувь, носки/чулки/колготки, сумки, очки, украшения, ремни, головные уборы, шарфы, перчатки, резинки для волос, бутылки, телефоны и другие аксессуары и предметы. Пришитые детали одежды, например завязки топа, описывать можно.

Исключение действует только для прямо запрошенных в комментарии предметов:

- `Опиши также очки` — добавятся очки, но не сумка и обувь.
- `Добавь сумку и обувь` — разрешены эти две категории.
- `Только одежду девушки слева` — уточнение человека.
- `Подробнее` или `опиши всё` — не разрешают исключённые категории.

Эти правила передаются модели при каждом запросе. Соблюдение смысловых ограничений зависит от модели; ответ доступен для редактирования. Сам промпт можно посмотреть кнопкой настроек в окне Pinterest → «Промпт и лимит ответа».

### Pinterest и изображения

Pinterest запрещает встраивание на чужие сайты (`X-Frame-Options: SAMEORIGIN` и CSP `frame-ancestors 'self'`). Поэтому используется отдельное окно браузера поверх Таверны; на мобильном устройстве это может быть вкладка. Если окно не появилось, разреши всплывающие окна для адреса Таверны. Вход в Pinterest и скачивание происходят на самом сайте. Автоматического переноса скачанного файла в расширение нет.

Поддерживаются JPG, PNG, WebP, GIF до 25 МБ; для GIF используется первый кадр. Перед запросом изображение преобразуется локально в JPEG с белым фоном и длинной стороной не более 2048 px. «Скачать оригинал» сохраняет прикреплённый файл без этого преобразования.

Запрос идёт через штатный сервис профилей SillyTavern с ключом, моделью, URL и пресетом выбранного профиля. Передаются только системные правила, комментарий и картинка. Текущий профиль чата не переключается, история чата в запрос не включается. Ключи отдельно в расширении не хранятся.

Профиль и лимит токенов сохраняются в настройках SillyTavern. Картинка, комментарий и результат остаются в памяти вкладки до перезагрузки. Закрытие окна отменяет активный запрос; есть отдельная кнопка отмены и тайм-аут 120 секунд. Для reasoning-моделей можно увеличить лимит ответа (по умолчанию 2048, максимум 8192).

## Проверка для разработки

Браузерный smoke-тест использует подставной контекст SillyTavern и не обращается к модели:

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/browser_smoke.py
```

Переменная `CHROMIUM_PATH` позволяет указать уже установленный Chromium. Проверяются сенсорный интерфейс, вкладки, меню, загрузка и преобразование картинки, передача изображения выбранному профилю, сохранение текущего подключения чата, вставка в черновик, ошибки, отмена, мобильная/альбомная/десктопная компоновка и сохранение переключателя иконки в сендбаре. `SCREENSHOT_PATH` задаёт путь к необязательному скриншоту мобильного окна.
